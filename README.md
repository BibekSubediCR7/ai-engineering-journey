## How Each Track Is Organised

Inside every track folder, files follow one naming pattern, so they read in order:

```
Session_01_<Topic>.ipynb          ← concept notes and examples
Session_01_Tasks.ipynb            ← exercises I solved
Interview_Questions_Week_1.ipynb  ← interview-style Q&A
Extra_<Topic>.ipynb               ← side topics
```
